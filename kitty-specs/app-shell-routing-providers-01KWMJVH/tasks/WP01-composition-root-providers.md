# WP01 — Composition Root (Providers & DI)

## Objective

Create the dependency-injection spine of the application. Construct **one** `EventBus` (lifetime = app session) and the three repository adapter singletons, then expose them app-wide via React Context. This is the foundation every other work package consumes through `useAppDeps()`.

## Context

**Why this WP first**: Every container and subscription needs the shared `EventBus` and the three repositories. Per C-002 there must be **exactly one** `EventBus` for the session, and per NFR-007 a developer must be able to confirm that exactly one of each adapter exists. Doing this with `useState` would re-create instances on every render or on StrictMode double-invoke; `useRef` is the correct lifetime primitive.

**Codebase facts you can rely on** (verified 2026-07-03):

- `EventBus` class lives at `@/shared/lib/event-bus` and is exported via `@/shared/lib`. Its constructor takes no arguments: `new EventBus()`. It exposes `subscribe(eventType, handler): Unsubscribe` and `publish(event): void`.
- The three repository singletons are **module singletons** already constructed at import time. Import them by their published names; **do not** call any constructor or factory:
  - `zustandCartRepository` (lower-case `z`) — `@/entities/cart/api/zustand-cart-repository`
  - `MockInventoryRepository` — `@/entities/product` (re-exported from the slice index)
  - `MockCouponRepository` — `@/entities/coupon` (re-exported from the slice index)
- The port types they implement:
  - `ICartRepository` — `@/entities/cart` — `{ getCart(): Promise<Cart>; saveCart(cart: Cart): Promise<void> }`
  - `IStockRepository` — `@/entities/product` — `{ findBySku(skuId): Promise<ProductVariant | null>; save(variant): Promise<void> }`
  - `ICouponRepository` — `@/entities/coupon` — `{ findByCode(code): Promise<Coupon | null> }`
- `src/app/index.ts` exists but is empty (0 bytes). You will write into it in T003.
- `src/app/providers/` does **not** exist yet; create it.

**FSD layer constraint** (C-001): `src/app/` is the top of the stack. It may import only from `pages`, `widgets`, `features`, `entities`, and `shared`. It must not be imported by any of those layers.

## Subtask T001 — Create `AppDeps` type + `AppDepsContext` + `useAppDeps` hook

**Purpose**: Define the dependency-injection shape and the React Context consumer hook that the rest of the app will use.

**File**: `src/app/providers/app-deps.ts` (new).

**Steps**:

1. Import the `EventBus` type and the three port types:
   ```ts
   import { createContext, useContext } from 'react'
   import type { EventBus } from '@/shared/lib/event-bus'
   import type { ICartRepository } from '@/entities/cart'
   import type { IStockRepository } from '@/entities/product'
   import type { ICouponRepository } from '@/entities/coupon'
   ```

2. Define the `AppDeps` interface as a `readonly` surface:
   ```ts
   export interface AppDeps {
     readonly eventBus: EventBus
     readonly cartRepo: ICartRepository
     readonly stockRepo: IStockRepository
     readonly couponRepo: ICouponRepository
   }
   ```

3. Create the context (default `null` so a missing provider fails loudly):
   ```ts
   export const AppDepsContext = createContext<AppDeps | null>(null)
   ```

4. Create the `useAppDeps` hook with a fail-fast guard:
   ```ts
   export function useAppDeps(): AppDeps {
     const ctx = useContext(AppDepsContext)
     if (ctx === null) {
       throw new Error('useAppDeps must be used within <AppProviders>')
     }
     return ctx
   }
   ```

**Validation**:
- [ ] `AppDeps` is `readonly` on every field (prevents accidental mutation by consumers).
- [ ] `useAppDeps()` throws with a clear message outside a provider.
- [ ] No value is constructed here — only types and the context object.

## Subtask T002 — Create `AppProviders` component

**Purpose**: Construct the `EventBus` exactly once per session and provide the four deps via `AppDepsContext`.

**File**: `src/app/providers/app-providers.tsx` (new).

**Steps**:

1. Imports:
   ```tsx
   import { useRef, type ReactNode } from 'react'
   import { EventBus } from '@/shared/lib/event-bus'
   import { zustandCartRepository } from '@/entities/cart/api/zustand-cart-repository'
   import { MockInventoryRepository } from '@/entities/product'
   import { MockCouponRepository } from '@/entities/coupon'
   import { AppDepsContext, type AppDeps } from './app-deps'
   ```

2. Build the deps object inside `useRef` so it is constructed exactly once across the component's lifetime (survives StrictMode's double-invoke, re-renders, and unmount/remount cycles within the same session):
   ```tsx
   export interface AppProvidersProps {
     children: ReactNode
   }

   export function AppProviders({ children }: AppProvidersProps) {
     const depsRef = useRef<AppDeps | null>(null)
     if (depsRef.current === null) {
       depsRef.current = {
         eventBus: new EventBus(),
         cartRepo: zustandCartRepository,
         stockRepo: MockInventoryRepository,
         couponRepo: MockCouponRepository,
       }
     }
     return (
       <AppDepsContext.Provider value={depsRef.current}>
         {children}
       </AppDepsContext.Provider>
     )
   }
   ```

**Why `useRef` and not `useState`**: `useState` would let a careless later refactor call the setter and replace the bus; `useRef` makes the single-instance invariant structural. The `if (ref.current === null)` lazy-init pattern is the React idiom for "construct once".

**Why reference the singletons directly**: They are already module singletons — the module has already done the "construct once" job. Re-wrapping them in `useRef` would be belt-and-suspenders without benefit.

**Validation**:
- [ ] `new EventBus()` appears at most once per session (the `useRef` + null-check pattern).
- [ ] The repository imports use the exact names from "Codebase facts" above.
- [ ] `children` is rendered inside `AppDepsContext.Provider`.
- [ ] `eslint` react rules pass (no missing deps, no unnecessary constructs).
