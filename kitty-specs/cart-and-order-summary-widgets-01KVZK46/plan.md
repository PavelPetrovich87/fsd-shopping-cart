# Implementation Plan: Cart and Order Summary Widgets

**Branch**: `main` | **Date**: 2026-06-25 | **Spec**: `kitty-specs/cart-and-order-summary-widgets-01KVZK46/spec.md`
**Input**: Feature specification from T-027

## Summary

Implement two presentation widgets in the FSD `widgets` layer:

- `CartList` renders the shopper's cart as a list of item rows or an empty-state fallback.
- `OrderSummary` renders the order financial summary and embeds the coupon input and checkout action.

Both widgets receive all data and callbacks via props so that any page can place them into any responsive layout without modification.

## Technical Context

**Language/Version**: TypeScript 5.9 with React 19
**Primary Dependencies**: React, Tailwind CSS v4, shadcn/ui components via `src/shared/ui`, existing FSD slices (`entities/cart`, `features/cart-actions`, `features/apply-coupon`, `features/checkout`)
**Storage**: N/A (presentational widgets)
**Testing**: Storybook 10.3.6 for visual states, Vitest Browser Mode for interaction smoke tests
**Target Platform**: Modern browsers, responsive viewports 320px-1920px
**Project Type**: Single-page web application (Vite 8)
**Performance Goals**: Widgets render without blocking data fetching; no extra bundle split required
**Constraints**: Widgets may only import from `entities`, `features`, and `shared` layers (C-001); must not import from `pages` or other `widgets` (C-002); `OrderSummary` must not compute monetary values internally (C-003)
**Scale/Scope**: Two widgets, ~4-6 files each, consumed by the existing cart page and any future checkout page

## Risk Notes

- `CartRow` already bundles quantity controls and a remove action. `CartList` only needs to map items to `CartRow` and forward callbacks; no duplication of `QuantitySelector` or `RemoveButton` is needed.
- `OrderSummary` must remain purely presentational: all monetary values are props.
- The consuming page must compute `discount` and `shipping` before passing them to `OrderSummary`.
